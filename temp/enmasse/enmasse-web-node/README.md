# En Masse Website

## Installation

**Step 1:** Run `brew install node` to install [NodeJs](https://nodejs.org/en/). 
You may need to install HomeBrew first with `/usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"`

**Step 2:** Run `npm install apostrophe-cli -g` to install Apostrophe CMS

**Step 3:** Run `git clone https://github.com/enmasse-entertainment/enmasse-web-node.git` to clone the repository

**Step 4:** Cd into the repository folder and run `npm install` to install the dependencies

**Step 5:** Run the project using `npm run start`

**Step 6:** The project should now be running on port 3000. Navigate to [http://enmasse.dev.enmasse.com:3000](http://enmasse.dev.enmasse.com:3000)
